System design / 06

Project architecture

SafeScan connects compiler-front-end ideas and automata algorithms to a focused ReDoS analysis workflow.

COURSE PROJECT
01 / COMPILER DESIGN

Parse and extract

A restricted regex parser creates an abstract syntax tree. Source mode extracts a limited set of regex literals from JavaScript-like code and reports matched patterns.

02 / AUTOMATA THEORY

Build state machines

Thompson's construction creates an ε-NFA. Subset construction generates a DFA. Partition refinement produces a smaller equivalent DFA.

03 / SECURITY ANALYSIS

Flag and verify

Structural heuristics flag suspicious nested repetition and ambiguous repeated alternatives. Equivalence checks compare supported regex languages before a repair can be marked equivalent.

Processing pipeline
IMPLEMENTATION MAP

Implemented

Flags selected structural warning signs. A finding is not a measured runtime result or universal proof of exploitability.

Limited
